15 Production Forensic Operations (v2.0)

      
Every operation executes in linear time O(n) with bounded context projections and zero native dependencies.

    


    

      

        

          packet_summary
          Triage
        

        
Global capture telemetry (<2KB JSON): duration, packet counts, protocol distribution (TCP/UDP/ICMP), and top 10 talkers.

      


      

        

          packet_list
          Inspection
        

        
Bounded, paginated packet inspection (default limit 20, max 100) with summary fields. Eliminates raw hex context bloat.

      


      

        

          packet_extract_conversations
          L4 Flows
        

        
Bidirectional 5-tuple flow aggregation. Ranks conversations by total bytes and tracks TCP lifecycle flags (SYN/ACK/FIN/RST).

      


      

        

          packet_extract_dns
          L7 DNS
        

        
RFC 1035 decoder with recursion loop protection. Resolves A, AAAA, CNAME, TXT, MX, and PTR records and ranks query frequencies.

      


      

        

          packet_extract_http
          L7 Web
        

        
Reassembles TCP streams into HTTP/1.x requests/responses. Decodes chunked encoding, caps bodies at 4KB, and flags cognitive hints.

      


      

        

          packet_extract_tls_sni
          L7 TLS
        

        
Sequential parsing of TLS 1.0–1.3 ClientHello records. Extracts Server Name Indication (SNI) hostnames without decryption.

      


      

        

          packet_detect_beacons
          Threat C2
        

        
Statistical time-delta variance (Coefficient of Variation) to detect C2 beacons. Includes Council benign filtering (NTP, cloud IMDS).

      


      

        

          packet_detect_dns_tunneling
          Exfiltration
        

        
Identifies DNS exfiltration channels (dnscat2, iodine) via character entropy, label length profiling, and hex/base64 detection.

      


      

        

          packet_extract_credentials
          Credential Hunt
        

        
Recovers exposed credentials from HTTP Basic, Digest, query params, POST bodies, FTP USER/PASS, and SMTP AUTH commands.

      


      

        

          packet_entropy
          Forensics
        

        
Shannon entropy (0.0 to 8.0 bits/byte) payload randomness classifier distinguishing plaintext, structured data, and encrypted malware.

      


      

        

          packet_ja3_fingerprints
          Threat Intel
        

        
Extracts and aggregates JA3, JA3S, and JA4 TLS client fingerprints. Flags known C2 profiles (Cobalt Strike, Metasploit, Sliver).

      


      

        

          packet_extract_websocket
          L7 WebSocket
        

        
Reassembles TCP streams and parses RFC 6455 WebSocket frames, unmasking client payloads and decoding text/JSON messages.

      


      

        

          packet_extract_quic_sni
          L7 QUIC / H3
        

        
Inspects unencrypted QUIC Initial Handshakes on UDP 443 to extract SNI hostnames, Connection IDs, and ALPN without keys.

      


      

        

          packet_filter_export
          Export
        

        
Filters PCAP/PCAPng captures by IP, port, protocol, or time window and generates clean, download-ready classic PCAP binaries.

      


      

        

          packet_to_zeek_logs
          SIEM Ingestion
        

        
Generates standardized Zeek TSV logs (conn.log, dns.log, http.log) for automated analysis in Splunk, ELK, or Wazuh.

What is PacketChef MCP and why was it built for AI agents?

          

            PacketChef MCP is the official zero-dependency Model Context Protocol (MCP) server for network packet analysis. Traditional tools like Wireshark and Scapy dump massive raw text or require native C bindings that crash LLM context windows. PacketChef runs on pure Node.js buffer arithmetic, parsing captures into bounded, token-efficient JSON summaries (<2KB) tailored for AI agent consumption.
          

        


        

          
How does PacketChef MCP compare to Wireshark and tshark?

          

            Unlike Wireshark/tshark, PacketChef MCP requires zero native binaries or system package installations (libpcap). It installs anywhere with npx, implements deterministic RFC grammar decoders for IPv4/IPv6, TCP reassembly, DNS, HTTP, TLS JA3/JA4, WebSocket, and QUIC, and is completely immune to C-level buffer overflows and ReDoS attacks.
          

        


        

          
Which AI coding tools and harnesses are supported?

          

            PacketChef MCP natively supports all MCP-compliant AI harnesses: Claude Code, Cursor, Windsurf, Codex, OpenCode, Kimi, and Strix. It supports both local stdio execution and remote cloud deployment over Server-Sent Events (SSE) on Azure App Service or Docker.
          

        


        

          
How does PacketChef MCP defend against indirect prompt injection?

          

            Network frames often contain attacker-controlled strings (malicious HTTP User-Agents, DNS queries, or prompt overrides). PacketChef MCP enforces strict forensic isolation, wrapping extracted data in passive provenance notices that instruct the host LLM to treat all decoded text as inert data rather than executable instructions.
          

        


        

          
Can PacketChef MCP detect stealthy C2 beaconing and DNS tunneling?

          

            Yes. packet_detect_beacons evaluates time-delta variance (Coefficient of Variation) to unmask periodic heartbeats with high statistical confidence while filtering benign NTP and cloud IMDS traffic. packet_detect_dns_tunneling profiles Shannon character entropy and subdomain label length to flag exfiltration tools like dnscat2 and iodine.
          

        


        

          
How should AI agents pair PacketChef MCP with CyberChef MCP?

          

            In modern incident response workflows, AI agents use PacketChef MCP to isolate TCP streams and extract obfuscated payloads, then invoke CyberChef MCP (@noorfatima123456/cyber-chef-mcp) to execute multi-stage deobfuscation recipes (Base64 → XOR → Gunzip → AES) and reveal cleartext indicators.
